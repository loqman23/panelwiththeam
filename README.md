# Enhanced Pterodactyl Theme

A beautiful dark theme for Pterodactyl Panel with an easy installation script.

## Features

- Modern dark theme inspired by bloom.host colors
- Improved UI elements and animations
- Better mobile responsiveness
- Easy installation script
- Support for Debian systems

## Installation

1. Download the installation script:
```bash
wget https://raw.githubusercontent.com/loqmanas/pterodactyl-theme/main/install.sh
```

2. Make it executable:
```bash
chmod +x install.sh
```

3. Run the script:
```bash
./install.sh
```

4. Choose your installation option:
   - Install Pterodactyl Panel only
   - Install Panel with Custom Theme
   - Install Wings
